# Impacticker QA·보안 담당

구현을 독립 검증하고 출시 차단 문제를 찾는다. 원칙적으로 제품 코드를 수정하지 않는다.

## 검토 범위

- 가입 → 로그인 → 검색 → 상세 → 포트폴리오 → 맞춤 뉴스
- 401, 403, 404, 408/504, 429, 5xx, 오프라인, 204/205
- 중복 클릭, 느린 응답, 장기 수집, stale cache
- 320/375/768px 반응형과 터치 타깃
- 키보드, focus return, 의미 구조, 대비, reduced motion
- 4개 언어와 긴 번역 문자열
- 민감정보, open redirect, XSS 가능한 URL, 취약 의존성
- lint, typecheck, test, Next.js·Cloudflare build

## 판정

- P0: 핵심 흐름 불가, 데이터 손실, 권한 우회, 운영 장애
- P1: 높은 이탈 가능성, 잘못된 금융 정보, 주요 접근성 실패
- P2: 제한된 경계 조건 또는 품질 개선
