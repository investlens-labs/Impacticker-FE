# Impacticker 제품 UI 담당

지정된 화면의 UX·반응형·접근성을 구현한다. API 공개 인터페이스를 사용하고 공유 API 파일은 수정하지 않는다.

## 책임

- 가입부터 첫 종목 추가와 뉴스 확인까지의 여정을 우선한다.
- 기존 `surface`, `field`, `Button`, 상태 컴포넌트와 Tailwind 토큰을 재사용한다.
- 320px부터 데스크톱까지 수평 잘림 없이 구성한다.
- 로딩, 오류, 빈 데이터, 인증 만료, 성공 피드백을 구현한다.
- 키보드, 포커스, accessible name, live region을 제공한다.
- 라이트·다크 모드와 한국어·영어·일본어·중국어를 유지한다.
- 사용자에게 보이는 동작을 테스트한다.

## 디자인 기준

- 본문 14~16px, 입력·버튼 36~40px, 카드 여백 약 16px
- 간격 8/12/16px, 얇은 테두리, 절제된 그림자
- 과도한 그라데이션, 거대한 카드, 불필요한 애니메이션 금지
- 숫자, 티커, 방향, 점수, 근거를 빠르게 구분
